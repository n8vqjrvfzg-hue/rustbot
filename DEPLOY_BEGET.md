# Развёртывание на Beget (пошагово)

## 0. Какой продукт Beget брать
Нужен **VPS** (облачный сервер с root-доступом), а не «виртуальный хостинг». Виртуальный хостинг рассчитан на сайты: там нет root, а постоянно работающие процессы вроде бота обычно не поддерживаются. На VPS всё работает как описано ниже.

- ОС: **Ubuntu 24.04** (на ней Python 3.12 — под него всё проверено).
- Тариф: **1 ГБ RAM / 1 ядро** хватает с запасом. Цены в обзорах разные (примерно 200–330 ₽/мес), оплата посуточная — точную цену смотри на странице заказа.
- Регион: сначала выбери тот, что ближе; после создания скрипт настройки сам проверит, достаёт ли сервер до Telegram и Steam. Если нет — пересоздай сервер в другом регионе (у Beget есть Россия, Казахстан и Латвия).

## 1. Создать сервер
Панель Beget → облачные сервисы / VPS → создать сервер → Ubuntu 24.04 → тариф → (лучше) добавить свой **SSH-ключ**, либо запомнить пароль root. В итоге у тебя будет **IP-адрес сервера**.

## 2. Подключиться
- **ПК (Windows):** PowerShell → `ssh root@IP_СЕРВЕРА`
- **Телефон:** приложение **Termius** → New Host → IP, пользователь `root`, пароль или ключ.

## 3. Загрузить бота
- **ПК:** `scp rustbot_stage10.zip root@IP_СЕРВЕРА:/tmp/`
- **Телефон:** Termius → SFTP → папка `/tmp` → загрузить архив.

## 4. Установить (на сервере, всего 3 команды)
```bash
apt update && apt install -y unzip
unzip -o /tmp/rustbot_stage10.zip -d /opt
bash /opt/rustbot/deploy/setup_server.sh
```
В конце скрипт покажет `HTTP 200/302/404` для Telegram и Steam. Любой код означает «доступ есть». «НЕТ ДОСТУПА» — смотри раздел «Проблемы».

## 5. Заполнить настройки `.env`
Самый удобный способ — подготовить файл на ПК (как у тебя сейчас) и отправить его на сервер:
```powershell
scp .env root@IP_СЕРВЕРА:/opt/rustbot/.env
```
Затем на сервере: `chmod 600 /opt/rustbot/.env && chown bot:bot /opt/rustbot/.env`.
(С телефона: `nano /opt/rustbot/.env`, сохранить `Ctrl+O`, `Enter`, выйти `Ctrl+X`.)

Что должно быть в `.env`: `BOT_TOKEN`, `ADMIN_GROUP_ID`, `APPLICATIONS_TOPIC_ID`, `SUPPORT_TOPIC_ID`, `COMPLAINTS_TOPIC_ID`, `TEAM_CHANNEL_ID`, `CHANNEL_ID`, `ADMIN_IDS`, `STEAM_API_KEY`, при желании `TIMEZONE`, `BACKUP_CHAT_ID`.
Файл `.env` никому не отправляй в мессенджерах.

## 6. ВАЖНО: остановить бота на своём ПК
Один токен можно использовать только в одном месте. Закрой окно с ботом на компьютере, иначе будет ошибка «Conflict: terminated by other getUpdates request».

## 7. Запустить
```bash
systemctl enable --now rustbot
botctl logs
```
В логах должна появиться строка «Бот @... запущен». Напиши боту `/start` и `/status`. Через ~5 минут в личку придут две первые резервные копии.

## 8. Управление: команда `botctl`
| Команда | Что делает |
|---|---|
| `botctl status` | состояние бота |
| `botctl logs` / `botctl logs 200` | последние строки логов |
| `botctl follow` | логи в реальном времени (выход `Ctrl+C`) |
| `botctl restart` / `stop` / `start` | перезапуск / остановка / запуск |
| `botctl update /tmp/архив.zip` | обновление версии |

**Обновление:** загрузи новый архив в `/tmp` (шаг 3) и выполни `botctl update /tmp/имя_архива.zip`. Файл `.env`, база `bot.db` и копии не затрагиваются.

## 9. С телефона и с ПК
- **Telegram-бот:** админ-меню, настройки, тех. работы, экстренный сбор, `/status`, `/backup`, `/export` — всё работает с любого устройства.
- **Сервер:** Termius есть для телефона и ПК, хосты и ключи синхронизируются между ними. На ПК можно ещё PowerShell или Windows Terminal; файлы — WinSCP или SFTP в Termius.
- **Панель Beget:** перезагрузка сервера, если SSH не отвечает, и резервные копии/снапшоты сервера (проверь, что они включены).

## 10. Безопасность
- Вход по SSH-ключу (в Termius ключ создаётся в пару нажатий). Когда ключ проверен, пароль root можно отключить.
- Фаервол уже включён (открыт только SSH), бот работает от отдельного пользователя `bot`.
- Раз в месяц: `apt update && apt upgrade -y`.
- Если токен засветился — перевыпусти в @BotFather (`/revoke`) и поменяй в `.env`.

## 11. Проблемы
| Симптом | Что делать |
|---|---|
| Скрипт показал «НЕТ ДОСТУПА» к Telegram | сервер не достаёт до api.telegram.org — создай VPS в другом регионе |
| `Conflict: terminated by other getUpdates` | запущена вторая копия бота (на ПК или в другом месте) |
| Бот молчит | `botctl status`, `botctl logs 100` |
| Не приходят анкеты/жалобы/обращения | бот не админ группы или нет права писать в топики, неверные ID в `.env` |
| Нет заявок в канале «Поиск команды» | бот не админ канала с правом публикации |
| «Привязка Steam не настроена» | пустой `STEAM_API_KEY` |
| Не пришли копии базы | владелец не нажимал /start у бота; проверь `BACKUP_CHAT_ID` |

## 12. Резервные копии
Подробности и восстановление — в `DEPLOY.md` (раздел 8): бот сам присылает копию базы и выгрузку CSV в Telegram, плюс копии лежат в `/opt/rustbot/backups/`.
